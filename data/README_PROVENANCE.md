# Example data - provenance, units, schema

Both files are **self-created and SYNTHETIC** (generated by `tools/make_example_data.py`, public domain / CC0).
**`example_synthetic_nodal_temperature.csv` is NOT an actual ANSYS export.**

| File | What it is | Units | Notes |
|---|---|---|---|
| `example_bracket.stl` | ASCII STL, 32-segment cylinder, 1 m long, radius 5.642 mm (A = 1e-4 m^2), 128 triangles. Name inside: `example_rod_synthetic` (the filename "bracket" is historical; it is a rod). | **metres** (STL stores no units; this is a documented assumption) | Outward normals; closed surface |
| `example_synthetic_nodal_temperature.csv` | 369 nodes: 41 axial stations x (1 axis + 8 rim nodes). T(x) = analytical rod solution (Task C) minus a synthetic 3 C radial dip. | x_m,y_m,z_m in **metres**; temperature_C in **degrees Celsius** | Range 17 - 188.2 C |

## CSV schema (matches the brief)
`node_id,x_m,y_m,z_m,temperature_C` - exact header, comma separated, one node per row, `node_id` unique non-negative integer,
all numeric fields finite, temperature > -273.15 C. UTF-8 BOM, CRLF and blank lines are tolerated.
A real ANSYS export (e.g. a Mechanical "Export" / APDL `PRNSOL,TEMP` post-processed to this header) must be converted to this schema and unit-checked by the user.

## Tested size limits (GCC 13, -O3, 1 logical CPU, 3.9 GiB RAM, Linux)
| Input | Size | Parse wall time | Peak RSS |
|---|---|---|---|
| ASCII STL, 400,000 triangles | 52 MB | 1.3 s | ~39 MB |
| Nodal CSV, 2,000,000 nodes | 80 MB | 2.0 s | ~163 MB |
| Any file > **256 MB** | - | rejected immediately with a message | - |
Rendering limits (browser/GPU) are not yet measured - see README "Known limitations".
